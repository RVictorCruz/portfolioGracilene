# Portfólio Profissional - Gracilene Castro

## 📌 Visão Geral

Este é um site portfólio profissional para Gracilene Castro, especialista em Liderança Estratégica em Logística. O site apresenta:

- Perfil profissional completo
- Trajetória e experiência
- Artigos e publicações
- Depoimentos de colegas
- Seção de contato

## ✨ Recursos Principais

✅ **Design Moderno e Responsivo**  
- Layout adaptável para todos os dispositivos
- Animações e efeitos visuais sutis
- Tipografia profissional e hierarquia visual clara

✅ **Seções Organizadas**  
- Hero section com call-to-action
- Sobre mim com habilidades técnicas
- Linha do tempo da experiência profissional
- Artigos centralizados e com destaque
- Depoimentos com carrossel
- Formulário de contato funcional

✅ **Tecnologias Utilizadas**  
- HTML5 semântico
- CSS3 com Flexbox e Grid
- JavaScript para interatividade
- Font Awesome para ícones
- Google Fonts para tipografia

## 🛠️ Estrutura de Arquivos

```
portfolio-gracilene/
├── index.html          # Página principal
├── css/
│   └── style.css       # Todos os estilos
```

## 🚀 Como Usar

1. Clone o repositório ou faça download dos arquivos
2. Abra o arquivo `index.html` no navegador
3. Para desenvolvimento:
   - Edite o CSS em `css/style.css`
   - Modifique o JavaScript em `js/script.js`
   - Atualize as imagens na pasta `images/`

## 🎨 Personalização

Para personalizar este portfólio:

1. **Conteúdo**:
   - Substitua textos no HTML
   - Atualize as experiências profissionais
   - Adicione/remova artigos

2. **Estilo**:
   - Modifique as cores em `:root` no CSS
   - Altere as fontes no cabeçalho HTML
   - Ajuste tamanhos e espaçamentos

3. **Imagens**:
   - Substitua `gracilene-profile.jpg` por sua foto
   - Atualize imagens dos artigos
   - Adicione mais depoimentos
